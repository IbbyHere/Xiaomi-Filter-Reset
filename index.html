Xiaomi Filter Reset
100% client-side · nothing leaves the browser

Reset the filter, not your wallet.

A browser-based tool that generates NFC reset commands for Xiaomi Air Purifier filters, so the "remaining life" counter can be brought back to 100% instead of forcing an early replacement.

Generate a reset command

Enter the 14-character UID read from the filter's NFC tag.

What this is

The filter's NFC tag tracks life on a timer, not on how dirty it actually is. So Mi Home keeps demanding a replacement even when the filter is still doing its job. This generates the reset code needed to bring that counter back to 100%, straight from the UID printed on the tag.

What it's for

Built for the Xiaomi Mi Air Purifier 4, and works the same way on every model using the same tag setup.

Flashing the tag

Using the free NFC Tools app on an NFC-capable Android phone.

1

Install NFC Tools

Grab the free NFC Tools app (by wakdev) from the Play Store.

2

Read the tag

Tap Read and hold the phone against the tag on the filter until it scans. Note the UID / Serial number shown (14 hex characters).

3

Generate the command

Paste that UID into the box above and hit Generate to get the reset command.

4

Open advanced commands

In NFC Tools, go to Other > Advanced NFC commands and accept the warning.

5

Set the I/O class

Set it to NfcA (ISO 14443-3A).

6

Paste the command

Paste the whole reset command into the data box, e.g. 1B...,3008,A20800000000.

7

Send it

Hold the phone against the tag again and tap Send command.

8

Check Mi Home

Open the app back up. The filter should now read 100% remaining life.

Disclaimer

Only flash a filter that's been checked and is still in good shape. This resets what the app reports, it doesn't clean or extend the actual filter. Writing raw NFC commands can occasionally fail partway through, so proceed at your own risk.
